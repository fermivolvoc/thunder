# Thunder's Stella Unibell Guide site

Generated static guide site from `ThundersStellaUnibellGuide.html`.

## Files
- `index.html` — the finished guide page.
- `images/` — put the 85 Google Drive images here. The HTML expects filenames like `image1.png`, `image2.png`, ...

## Deploy
1. Download/extract this folder.
2. Download all image files from the Google Drive folder supplied by the user.
3. Put the image files inside `images/` next to `index.html`.
4. Deploy the whole folder to Cloudflare Pages, Netlify, Vercel, GitHub Pages, or any static host.
